# 失效模式分析：从"身份错配"到"选人错误"（论文核心素材）

> 2026-09-23 在 C 组场次 30.1 全量 24279 帧（200 fps，5 视角）上的实证调查。
> **结论：主流叙事"多视角 3D 姿态的难点是身份歧义"不完整；在真实对抗场景里，
> 更致命的是"选人错误"——检测/跟踪把第三方（观众/教练/裁判）当成了运动员。**

---

## 一、现象（可复现）

同一套定稿参数、同一组标定，**场次 30.1** 的 3D 在特定时段崩掉，而 **1.1 / 0.1 完全正常**：

| 指标 | 正常段（30.1 的 16000–20000） | 崩段（30.1 的 8000–12000） |
|---|---|---|
| 2D 重投影 残差 p90 | 17–142 px | **260–434 px** |
| 三角化层骨长 CV 中位 | 0.03 级 | **0.55** |
| 视角间"身份打架"帧 | 0.3 % | **17–49 %** |

## 二、逐层排除（每一层都有量测，不是推理）

| 层 | 结论 | 证据 |
|---|---|---|
| **2D 关键点** | ✅ 干净 | 崩段 conf 中位 0.79–0.85、低置信关节 0–6%、左右臂长不对称 0.05–0.24 —— 与正常段同级 |
| **检测框数量/健康度** | ✅ 干净 | 全片零框率 0.0%、双框率 99.4–100%、无出界 |
| **内参/外参** | ✅ 干净 | C 组主视角内参与 A 组**逐位相同**；外参同一份；全库探针残差 7–12 px |
| **三角化/fit 参数** | ✅ 同口径 | λ=3 / k=100 / 滤波 5+41，与 A 组逐字相同 |
| **conv 的颜色挑路径** | ⚠️ 真缺陷（已修）但**非崩因** | 用"2D 自带 personID"替代后覆盖率 24%→0%，**残差几乎不变** |
| **翻转曲线滞后** | ⚠️ 存在但**非崩因** | 跨视角+几何耦合定标把跳变点 27→5~10，**崩段仍不变** |
| **★ 选人错误（同色配对）** | **❌ 崩因** | 见下 |

## 三、崩因：崩段里"选进来的两个人不是一对选手"

对抗双方**必然一红一黑**，所以"两个检测框的颜色必须不同"是一条**免费且强**的合法性判据。
逐时段 × 逐视角统计（合法 = 一红一黑；同色 = 两框同色 = 一个选手 + 一个外人/重复框）：

| 场次 | 崩段 v3 | 崩段 v4 | 崩段 v7 | 正常段 |
|---|---|---|---|---|
| **30.1（崩）** | **同色 88% / 71%** | 55% / 11% | 12% / **44%** | 0–4% |
| 1.1（好） | ≤21% | ≤43% | ≤7% | ≤7% |
| 0.1（好） | ≤9% | ≤6% | ≤6% | — |

**崩段里多数视角超过一半的帧"同色"** —— 三角化被喂进**错的人**。
而错的观测**在任何单视角内部都看起来完全合理**（真人的合理姿态、高置信度 0.9+）。

## 四、为什么现有机制救不了

1. **"同色 ⇒ 单人帧"规则被距离门限卡死**：手册里的规则要求两条 annot **距离 <50 px** 才判"同一人被复制"；
   而真实情况是**两个同色的人相距 300 px**（选手 + 观众）→ 规则不触发。
2. **"取面积最大 2 框"会被外人抢位**：候选列表存在，但选的时候不看颜色。
3. **★ 鲁棒三角化只对"缺失观测"鲁棒，对"自信的错观测"无能为力**：
   视角子集枚举 / RANSAC 能吃掉少数派离群点，但**错观测是"真人的合理姿态"**——它不表现为数学离群。

## 五、三条候选修法（都很小，互相独立）

| # | 位置 | 做法 |
|---|---|---|
| A | 检测选人层（`stage1_detect`） | **外观互补约束**：取 top-2 后校验两框颜色；同色则从候选里换一个颜色互补的进来（配时序连续性） |
| B | conv 单体帧规则（`stage4_assemble`） | **"同色即单人"去掉 d01<50px 门限**：两人同色 ⇒ 无论多远都按单人处理，只保留颜色匹配的 pid |
| C | conv → 三角化之间 | **违规视角降级为缺失**：配对不合法/不可判 ⇒ 该 (帧,视角) 对两个 pid 都写全 0，让鲁棒三角化把它当"没看到"而非"看到了别人" |

**验收口径**：① 同色率回到正常段水平（<5%）；② 崩段残差 p90 从 400+ px 回到 20–50 px；③ 骨长 CV 从 0.55 回到 0.03 级。

## 六、对论文的意义

**Gap 陈述**：
> 现有多视角 3D 姿态管线（含以"身份歧义"为主题的工作）通常假设**场上只有目标人物**；
> 在真实的对抗/混乱场景（有第三方进场）中，**"选人错误"是比"身份翻转"更致命的失效模式**，
> 且它对所有"单视角内的一致性检查"隐形——因为错的观测是真人、合理、高置信的。
> 我们给出量化签名（同色配对率），并提出**外观互补约束 + 违规视角降级**的解法，
> 使鲁棒三角化重新生效。

**与对标工作的差异**：Feiz et al. 2025（拳击多视角）走**物理优化**路线；本工作是
**外观/身份建模 + 观测合法性**路线，机制不同、可正面比较。

**可量化的卖点**（对应"场景混乱 + 可量化"）：
- 输入多视角视频（或自己的检测框）→ 直接产出 13 节点 3D 序列，不是 demo；
- 三组分辨率 × 两种帧率都跑通，参数可迁移（λ∝fps²、k∝fps⁴ 的推导 + 实测）；
- 全链有量化验收（2D 重投影 / 骨长 CV / 帧间抖动 / 身份打架率），任何一段坏了都能定位到帧。
